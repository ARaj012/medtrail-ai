# MedTrail – Member 5: Machine Learning and AI Summaries

Disease risk models (diabetes, kidney, liver, heart) with SHAP explanations,
anaemia and blood-pressure screening, trend alerts, and patient- and
doctor-friendly medical-history summaries for the MedTrail project.

Academic prototype using public and synthetic data only. It is not a medical
device: risk scores are screening estimates, never diagnoses.

Status: in development.
